Glossary ​

This page explains the common words you may see during detection and recovery.

Fee Terms ​

  • Service Fee: 0.5% of recovered value, minimum 1 USDC.
  • Withdrawal Fees: Hyperliquid withdrawal fee, usually 2 USDC total.
  • Total Cost: Service Fee + Withdrawal Fees.
  • You Will Receive: estimated/actual user settlement amount.

Accounts and Assets ​

  • SPOT: regular token balances in your spot account.
  • PERP: perpetual positions or balances related to perpetual trading.
  • VAULT: assets held in vaults; some may be temporarily locked.
  • STAKED: HYPE balances that are in a staking-related state.

Staking States ​

  • HYPE-STAKED: HYPE is still actively staked and cannot be withdrawn immediately.
  • HYPE-UNSTAKED: HYPE has left active staking and is ready for a later step.
  • HYPE-PENDING: withdrawal has been initiated and is still in the waiting period.

Step-Level Statuses ​

  • completed: this step finished successfully.
  • completed_partial: this step finished only in part; some assets may still need follow-up.
  • completed_waiting: this step finished, but you must wait before the next action.
  • skipped_locked: this step was skipped because the asset is currently locked.
  • skipped_no_assets: this step was skipped because there was nothing eligible to process.
  • failed_*: this step failed because of a system, input, or network issue.

Task-Level Outcomes ​

  • completed: this run made real progress or recovered funds, and you do not need to rerun it right now.
  • partial: this run only finished in part, or nothing was recovered yet while some assets are still blocked or waiting.
  • waiting_to_rerun: this run progressed correctly, but you still need to wait and run it again later.
  • failed: this run stopped because of a fatal error.
