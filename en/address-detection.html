Address Detection

Address Detection

Address Detection gives you a fast, read-only view of account assets before recovery.

Detection Scope

  • Spot assets
  • Perpetual balances and positions
  • Vault assets and whether they are temporarily locked
  • Staking-related balances and waiting stages

Input Requirements

  • Address format: 42 chars with 0x prefix
  • Mixed case supported; copying the address directly from your wallet is recommended
  • No private key needed for detection

Output

  • Total USD value estimate
  • Asset list by category
  • Waiting or lock indicators
  • Whether anything can be handled right now

Example Output

Address: 0x1234...7890
Total Value: $1,234.56

[SPOT] USDC: 500.00 ($500.00)
[SPOT] ETH: 0.5 ($734.56)
[PERP] BTC-PERP: 0.001 ($45.00)
[VAULT] USDC: 100.00 ($100.00) - locked
[STAKED] HYPE-STAKED: 50.00

Recoverable: Yes

Status Notes

  • locked: this asset cannot be handled yet; try again after the lock ends
  • pending: this asset is still in a waiting stage and may need another run later
  • price unavailable: the balance is detected, but the market price is temporarily unavailable

Recommended Next Steps

  1. Confirm the same source address can receive normally on Arbitrum.
  2. If locked or pending exists, set a rerun reminder.
  3. Run detection again right before recovery for fresh balances/prices.

Troubleshooting

  • Invalid address: check prefix, length, and characters
  • Timeout: verify network and retry
  • Missing prices: usually liquidity/market data delay; retry later
