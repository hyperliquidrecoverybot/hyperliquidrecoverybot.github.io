Features

Features

This page defines product capabilities and operational boundaries.

Core Capabilities

  • Multi-account detection across Spot / Perp / Vault / Staked
  • Standardized 7-step recovery execution
  • Unified fee semantics: Service Fee / Withdrawal Fees / Total Cost / You Will Receive
  • Step-level execution status with next-action hints
  • On-chain verifiability via transaction hashes

Supported Scenarios

  • Address is flagged and typically cannot be fully operated in frontend
  • Need unified conversion to USDC and final withdrawal
  • Need auditable and repeatable recovery flow

Protocol Boundaries

  • No bypass of protocol rules (lockup, waiting windows, min withdrawal)
  • Locked assets are deferred until unlock
  • Staked assets may require 2-3 runs depending on current state

Fee Transparency

  • Service Fee: 0.5%, minimum 1 USDC
  • Withdrawal Fees: 2 USDC (two withdrawals)
  • Estimated values shown before execution, actual values after execution

Security Model

  • Use only the official bot entry
  • Never provide your private key or mnemonic outside the bot's official recovery flow
  • Use transaction hashes and on-chain results to verify completed actions

Out of Scope

  • No investment advice
  • No override of protocol lock/unlock mechanics
  • No guarantee of instant completion under external network instability
